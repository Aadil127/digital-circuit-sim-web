# Digital Circuit Simulator

Built using [iced](https://github.com/iced-rs/iced/), the web build is packaged using [trunk](https://github.com/trunk-rs/trunk).

Try to [Launch sim](https://aadil127.github.io/digital-circuit-sim-web/).

It is still in early stage for wasm build.

---

### Some basic shortcuts
|Actions| keys    |
|-------|---------|
|search saved circuit| ctrl + F|
|Undo| ctrl + Z|
|Redo| ctrl + Y|
|Save circuit| ctrl + S|
|Force temp file save| ctrl + shift + S|
|Duplicate selected elements| ctrl + V|
|Toggle grid lines| ctrl + L|
|Toggle grid snapping| ctrl + G|
|Zoom in| ctrl + + or ctrl + =|
|Zoom out| ctrl + -|
|Step sim one Step (when simulator is paused)| ctrl + .|

---

#### To move around work space
- Holding middle mouse button and dragging.
- Holding spacebar while dragging mouse with left button pressed.
